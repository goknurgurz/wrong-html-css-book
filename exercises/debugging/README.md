# Hata Ayıklama Laboratuvarı

Bu klasörde bilerek bozulmuş küçük HTML/CSS örnekleri bulunur. Bunlar ana projeyi bozmaz; ayrı ayrı açarak test et.

## Kurallar
1. Önce tarayıcıda çalıştır ve hatayı tarif et.
2. Sorunu tek cümleyle yaz.
3. Hangi satırın veya kuralın neden sorun yarattığını açıkla.
4. Düzeltmeyi uygula ve tekrar test et.
5. En son `solutions/` klasöründeki açıklamayla karşılaştır.

**Öğretmen notu:** Çözümleri öğrenciye baştan verme; hata türünü söyleyerek ipucu ver.
