# GitHub Teslim Rehberi

1. GitHub'da `kitap-kosesi` adında yeni bir repository oluştur.
2. VS Code terminalinde proje klasörüne gel.
3. Komutları sırayla çalıştır:

```bash
git init
git add .
git commit -m "chore: initialize KitapKöşesi project"
git branch -M main
git remote add origin REPOSITORY_URLINI_BURAYA_YAZ
git push -u origin main
```

4. Her aşama sonunda küçük ve açıklayıcı commit oluştur. Örnekler:
   - `feat: add catalog page structure`
   - `style: create responsive book grid`
   - `fix: correct contact form labels`
   - `docs: update responsive test report`
5. GitHub'da dosyaların ve README'nin doğru göründüğünü kontrol et.
6. Teslim mesajında repository bağlantısını ve tamamladığın aşamaları yaz.

**Dikkat:** `REPOSITORY_URLINI_BURAYA_YAZ` yerine kendi repository adresini koy. Bu örnek adres değildir.
