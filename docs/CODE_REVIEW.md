# Code Review Kontrol Listesi

Her maddeye **Evet / Hayır / Emin değilim** olarak cevap ver ve Hayır/Emin değilim maddeleri için düzeltme planı yaz.

## HTML kalitesi
- [ ] Belge `<!doctype html>` ile başlıyor.
- [ ] Her sayfada `lang="tr"` ve viewport meta etiketi var.
- [ ] Sayfada tek bir ana `main` bölgesi var.
- [ ] Başlık seviyeleri mantıklı sırada ilerliyor.
- [ ] Bağlantıların metni hedefi anlatıyor.
- [ ] Her form alanının görünür veya erişilebilir bir etiketi var.
- [ ] Form kontrollerinde uygun `type`, `name`, `id` kullanılmış.
- [ ] Dekoratif öğeler ekran okuyucuya gereksiz bilgi vermiyor.
- [ ] İç içe HTML etiketleri doğru kapatılmış.

## CSS kalitesi
- [ ] Renk ve ölçüler için değişkenler kullanılıyor.
- [ ] Ortak bileşenlerin stilleri tek bir yerde tutuluyor.
- [ ] Selector'lar gereksiz derecede karmaşık değil.
- [ ] `!important` kullanımı gerekçesiz değil.
- [ ] Mobilde yatay taşma yok.
- [ ] Hover dışında klavye odağı da görünür.
- [ ] Metin kontrastı yeterli.
- [ ] Kullanılmayan CSS kuralları temizlenmiş.

## Proje ve teslim
- [ ] Göreli dosya yolları tüm sayfalarda doğru.
- [ ] Kırık bağlantı veya boş `href="#"` bırakılmamış; varsa gerekçesi yazılmış.
- [ ] Commit mesajları anlamlı ve küçük değişiklikleri yansıtıyor.
- [ ] README'de kurulum, sayfalar ve bilinen sınırlamalar açıklanmış.
- [ ] Öğrenci yaptığı önemli CSS/HTML kararlarını açıklayabiliyor.
